# K-Visa Assist — 성장 전략 (Growth Strategy)

> `docs/PLANNING.md`의 서비스를 전제로, 단일 행정사 사무소 서비스에서
> 플랫폼으로 확장하기 위한 단계별 전략입니다.
> ⚠️ 플랫폼(중개) 확장의 법적 제약은 `docs/LEGAL_REVIEW.md`를 반드시 함께 볼 것.

---

## 1. 성장 단계 로드맵 (3-Stage)

```
Stage 1. 단일 사무소 수직화       Stage 2. 공급자(행정사) 도구화        Stage 3. 플랫폼화
"우리 사무소의 AI 접수 채널"  →  "행정사용 케이스관리 SaaS"      →  "광고형 마켓플레이스"
(수임 매출)                      (구독 매출)                        (광고 매출)
```

핵심 논리: **처음부터 중개 플랫폼으로 가지 않는다.**
- Stage 1에서 소비자 수요와 전환 데이터를 검증하고,
- Stage 2에서 행정사들을 '고객(SaaS 사용자)'으로 먼저 확보한 뒤,
- Stage 3에서 법적으로 안전한 **광고형** 모델로 양면 시장을 연결한다.
- 이 순서는 로톡·삼쩜삼 등 자격사 플랫폼의 규제 리스크를 우회하는 검증된 경로이기도 하다.

---

## 2. Stage 1 — 단일 사무소 수직화 (0~12개월)

목표: **AI 챗봇 → 수임 전환 퍼널의 완성과 검증**

### 고객 획득 (Acquisition)
| 채널 | 실행 |
|---|---|
| 다국어 SEO 콘텐츠 | 비자 유형별 가이드 페이지 (영/중/베/한) — "E-7 visa requirements 2026" 류 롱테일 키워드. 하이코리아 정보는 한국어 중심이라 **영문 콘텐츠 공백이 큼** = 기회 |
| 커뮤니티 | 유학생 페이스북 그룹, 베트남/중국 커뮤니티(Zalo, WeChat), 레딧 r/korea·r/Living_in_Korea, 외국인 유튜버 협업 |
| 숏폼 | "비자 거절되는 5가지 이유" 류 TikTok/Instagram Reels — 비자 콘텐츠는 절박한 수요라 전환율이 높음 |
| 오프라인 접점 | 출입국청 인근, 대학가, 외국인 밀집 지역 (단, 옥외·전단 광고는 행정사회 광고 규정 확인) |

### B2B2C 파트너십 (초기 성장의 핵심)
- **대학 국제처/어학당**: D-2·D-4 학생 온보딩 패키지 제공
- **외국인 고용 기업 HR**: E-7·E-9 채용 시 비자 대행 계약 (기업이 지불 → 객단가 상승)
- **유학원·리크루팅 에이전시**: 현지(베트남·인도 등) 송출 단계부터 연결
- **지자체 외국인지원센터·글로벌센터**: 무료 상담 제휴로 신뢰 구축

### 전환·유지 (Activation & Retention)
- 챗봇 상담 완료 → 견적/체크리스트 자동 발급까지 **5분 내** 완료 (Aha moment)
- 비자 만료 **90/60/30일 전 알림** → 연장 수임 재발생 (비자는 반복 구매 상품!)
- 처리 결과·후기 축적 → "승인률" 데이터가 곧 신뢰 자산

### 검증 지표 (North Star: 월 수임 건수)
- 상담 시작 → 수임 전환율 (목표 5%+)
- CAC < 건당 대행 보수의 1/3
- 재수임률 (연장/변경 회귀율)

## 3. Stage 2 — 행정사용 SaaS (12~24개월)

목표: **플랫폼화 이전에 '공급자 네트워크'를 SaaS 고객으로 확보**

- Stage 1에서 만든 내부 도구를 상품화: 케이스 관리, 서류 체크리스트 자동 생성,
  고객 다국어 메시징, AI 서류 검토(OCR), 하이코리아 정보 최신화 알림
- 가격: 무료 티어(월 N건) + 구독제 — 행정사의 이탈 비용을 만들어 락인
- 이 단계의 자산: **전국 행정사 네트워크 + 표준화된 업무 데이터**
- 법적 성격: 순수 B2B 소프트웨어 판매 → 알선 이슈 없음 (LEGAL_REVIEW §4.2)

## 4. Stage 3 — 광고형 마켓플레이스 (24개월~)

목표: 소비자 트래픽(수요)과 행정사 네트워크(공급)를 **광고형 모델**로 연결

- 행정사가 **정액 광고료/구독료**를 내고 프로필·전문분야를 노출 (로톡 방식)
- 소비자와 행정사의 수임 계약은 **당사자 간 직접 체결**, 플랫폼은 계약·보수에 불개입
- **건별 성과 수수료·수임료 분배는 하지 않는다** — 중개형 전환 시 위법 소지 (LEGAL_REVIEW §3)
- 차별화: AI 사전 상담으로 사건을 구조화한 뒤 연결 → 행정사 입장에서 '정리된 리드'
- 신뢰 장치: 자격 검증(출입국민원 대행기관 등록 여부 표시), 후기, 응답 속도 배지

---

## 5. 해자(Moat) 만들기

1. **데이터 해자**: 비자 유형×국적×조건별 상담·승인 데이터 축적 → AI 정확도는 후발 주자가 따라오기 어려움
2. **콘텐츠 해자**: 다국어 비자 가이드 SEO 자산 (도메인 권위 선점)
3. **워크플로 해자**: 행정사 SaaS 락인 — 업무 도구를 장악하면 플랫폼 전환 비용이 낮아짐
4. **신뢰 해자**: 승인률·후기·처리 속도의 공개 실적

## 6. 수익 모델 진화

| 단계 | 수익원 |
|---|---|
| Stage 1 | 대행 보수 (건당), 기업 계약 (연간) |
| Stage 2 | SaaS 구독료 |
| Stage 3 | 정액 광고료, 프리미엄 노출 |
| 부가 | 공증 번역·아포스티유 제휴, 외국인 대상 통신/은행/보험 제휴 수수료(비자 업무 외 영역) |

## 7. 확장 옵션 (장기)

- 국가별 현지화 진출: 베트남·인도 현지 사전 상담 → 재외공관 사증 신청 연계
- 인접 영역: 외국인 창업(D-8), 영주(F-5), 국적 귀화 — 객단가 상승 경로
- 역방향: 한국인의 해외 비자(미국·일본 등)로 같은 엔진 재활용

## 8. 리스크 관리

| 리스크 | 대응 |
|---|---|
| 중개·알선 규제 (최대 리스크) | 광고형 모델 고수, 단계별 법률 자문 — `LEGAL_REVIEW.md` |
| 하이코리아 정보 변경/수집 제한 | 공공데이터 API 우선, 변경 감지 파이프라인, 행정사 검수 |
| AI 오답변 (잘못된 비자 안내) | 참고용 고지 + 수임 전 행정사 검토 의무화, 답변 근거(출처) 표시 |
| 개인정보 (여권 등 민감정보) | 암호화 저장, 보관기간 정책, 개인정보보호법 준수 감사 |
| 대한행정사회와의 갈등 | 로톡-변협 사태 학습: 초기부터 행정사회와 협력 관계 구축, 행정사 '도구'로 포지셔닝 |
