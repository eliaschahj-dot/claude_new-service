# 수수료 & 대행 보수 요율표 (초안)

> 정부 수수료는 출입국관리법 시행규칙 및 공개 안내 기준, 대행 보수는 **업계 요금
> 공개 사무소들의 평균 범위**를 조사해 책정한 초안입니다.
> 최종 요율은 대표(변호사·행정사) 승인으로 확정하며, 서비스 화면·견적 카드에는
> 이 표의 값이 지식베이스(`fees` 테이블)를 통해 노출됩니다.
> 조사 시점: 2026-07. `[확인]` 표시는 접수 전 최신 고시 재확인 필요 항목.

## 2. 대행 보수 요율표 (업계 평균 기반)

조사 근거: 요금을 공개한 행정사 사무소들의 신청대행 요금대 —
체류자격변경 36~44만원, 체류기간연장 28~36만원, F-6 신청대행 30~38만원,
F-5 변경 46~54만원(풀 서비스 80~150만원), E-7 풀 패키지 50~120만원.

### 2.1 표준 요율 (VAT 별도)

| 코드 | 업무 | 업계 평균 범위 | **책정 요율** | 착수금/잔금 |
|---|---|---|---|---|
| 공통 | 체류기간 연장 (단순) | 28~36만 | **300,000** | 15만 / 15만 |
| D-2·D-4 | 유학생 연장 | 20~30만 | **250,000** (학생 요율) | 10만 / 15만 |
| D-2·D-4 | 자격 변경 (D-4→D-2 등) | 36~44만 | **380,000** | 19만 / 19만 |
| D-10 | 구직 변경/신규 (점수제 평가 포함) | 36~44만 | **400,000** | 20만 / 20만 |

### 2.2 난이도 가산 (사전 고지 후 적용)

| 사유 | 가산 |
|---|---|
| 과거 거절 이력 있는 재신청 | +30~50% |
| 출입국관리법 위반 이력 (범칙금·초과체류 등) | +50% (사전 상담 필수) |
| 긴급 처리 (만료 7일 이내 착수) | +20% |
| 서류 원격 발급 대행 (본국 서류 아포스티유 등) | 실비 + 건당 5~10만 |

### 2.3 변호사 업무 (거절 대응 — 별도 수임)

| 업무 | 요율 |
|---|---|
| 거절 사유 분석 상담 (기존 수임 고객) | 무료 1회 |
| 이의신청 | 개별 견적 (통상 100만~) |
| 행정심판·행정소송 | 개별 견적 + 성공보수 협의 |

### 2.4 B2B (기업·학교 볼륨 계약)

- 연 5건 이상 약정: 표준 요율의 10% 할인
- 연 20건 이상: 15% 할인 + 전담 채널
- 대학 국제처 제휴: 학생 요율 추가 인하분은 제휴 조건으로 협의

### 2.5 환불 규정 (약관 반영)

| 시점 | 환불 |
|---|---|
| 착수 전 (서류 검토 시작 전) | 전액 |
| 서류 검토 착수 후 ~ 접수 전 | 착수금 공제 후 잔액 |
| 접수 후 | 환불 불가 (정부 수수료 포함) |
| 사무소 귀책 (기한 도과 등) | 전액 + 재신청 무상 |
| 심사 거절 | 보수 환불 없음 — 단, 재신청 30% 할인 or 이의신청 상담 무료 |

## 3. 운영 메모

- 광고·화면 표기는 행정사법 제22조의 거짓·과장 광고 금지에 유의: "승인 보장",
  "100% 발급" 문구 금지. "누적 처리 N건, 승인률 N%" 같은 사실 기반 표기만 사용.
- 요율은 `fees` 테이블 버전 관리 — 견적 시점의 요율이 계약에 고정되도록 스냅샷 저장.
- 대한행정사회 보수 관련 회규(기준·권고)가 있는지 확인 후 필요 시 조정. `[확인]`
