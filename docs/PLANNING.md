# K-Visa Assist — 외국인 한국 비자 발급 대행 서비스 기획서 (초안)

행정사 사무소가 운영하는 **AI 챗봇 기반 외국인 비자 발급 대행 모바일 웹앱**의 초안 기획 문서입니다.

---

## 1. 서비스 개요

| 항목 | 내용 |
|---|---|
| 서비스명(가칭) | K-Visa Assist |
| 운영 주체 | 변호사·행정사 사무소 (출입국민원 대행기관, 거절 시 불복 절차까지 원스톱) |
| 핵심 가치 | 외국인이 한국어를 몰라도, 챗봇과 대화만으로 비자 신청 서류 준비부터 접수 대행까지 완료 |
| 형태 | 모바일 우선(mobile-first) 반응형 웹앱 (PWA 확장 가능) |
| 주요 언어 | 영어(기본), 한국어, 중국어, 베트남어 (다국어 확장) |

### 문제 정의
- 외국인은 비자 종류(E-7, D-2, F-6 등)와 요건, 필요 서류를 파악하기 어렵다.
- 하이코리아(hikorea.go.kr) 정보는 한국어 중심이고 탐색이 복잡하다.
- 행정사 상담은 시간·언어 장벽이 있다.

### 해결 방식
1. **AI 챗봇 상담** — 국적, 체류 목적, 학력/경력 등을 대화로 수집 → 적합한 비자 유형과 요건을 안내
2. **서류 수집** — 필요한 서류 체크리스트를 자동 생성, 사진/파일 업로드로 제출
3. **대행 접수** — 행정사가 수임하여 하이코리아 전자민원/방문 접수 대행, 진행 상태를 앱에서 실시간 확인

## 2. AI 지식 베이스 (hikorea.go.kr 활용)

챗봇의 답변 근거가 되는 지식 베이스는 하이코리아의 공개 정보를 수집·정제하여 구축합니다.

### 수집 대상
- 체류자격(비자 유형)별 안내: 자격 요건, 체류 기간, 활동 범위
- 비자별 제출 서류 목록
- 수수료, 처리 기간, 신청 절차
- 전자민원 신청 안내, 출입국·외국인청 관할 정보
- 공지사항/정책 변경 사항

### 구축 파이프라인 (제안)
```
hikorea.go.kr 수집(크롤러/공공데이터 API)
   → 정제·구조화(비자유형별 JSON)
   → 임베딩 후 벡터 DB 저장
   → RAG 방식으로 LLM(챗봇)에 근거 제공
   → 주기적(주 1회) 갱신 + 변경 감지
```

### ⚠️ 법적·정책 유의사항
- 하이코리아는 법무부 운영 사이트이므로 **콘텐츠 이용 정책(공공누리 등)과 robots.txt를 반드시 확인**하고, 가능하면 공공데이터포털(data.go.kr)의 공식 API를 우선 사용합니다.
- 챗봇 답변에는 "본 안내는 참고용이며, 최종 판단은 출입국·외국인청 및 담당 행정사의 확인을 따릅니다" 고지 필요.
- 개인정보(여권, 신분증 등) 처리에 대한 개인정보처리방침·수집동의 절차 필수.

## 3. 타깃 사용자 & 페르소나

| 페르소나 | 상황 | 니즈 |
|---|---|---|
| 유학생 A (베트남) | D-2 연장 / D-10 변경 희망 | 무엇을 준비해야 하는지 모국어로 알고 싶음 |
| 엔지니어 B (인도) | E-7 취업비자 신규 | 회사 서류 + 개인 서류를 빠짐없이 준비하고 싶음 |
| 결혼이민자 C (중국) | F-6 신청 | 절차가 복잡해 전문가가 대신 처리해주길 원함 |
| 행정사 (운영자) | 사건 수임·처리 | 고객 정보/서류를 한 곳에서 관리, 진행 상태 업데이트 |

## 4. 핵심 기능

### 사용자(외국인) 측
1. **AI 비자 상담 챗봇** — 대화형 질의응답, 비자 유형 추천, 요건/서류/수수료/기간 안내
2. **비자 정보 탐색** — 비자 유형별 카드형 브라우징 (챗봇 없이도 검색 가능)
3. **신청서 작성 마법사** — 챗봇 대화에서 수집한 값으로 신청 정보 자동 채움
4. **서류 업로드** — 체크리스트 기반, 카메라 촬영/파일 업로드, 상태(검토중/승인/보완요청) 표시
5. **진행 상태 추적** — 타임라인 UI (상담 → 서류준비 → 검토 → 접수 → 심사 → 결과)
6. **행정사 연결** — 챗봇으로 해결이 안 되면 담당 행정사와 메시지/예약 상담
7. **결제** — 대행 수수료 + 정부 수수료 안내 및 온라인 결제

### 행정사(관리자) 측 — 2차 범위
- 사건(케이스) 대시보드, 서류 검토/보완 요청, 상태 업데이트, 고객 메시징

## 5. 사용자 플로우

```
[온보딩/언어 선택]
      │
[홈] ─── 비자 정보 탐색 (브라우징)
      │
[챗봇 상담] 국적/목적/조건 문답 → 비자 유형 추천
      │
[신청 시작] 개인정보 입력 (챗봇이 수집한 값 자동 채움)
      │
[서류 업로드] 자동 생성된 체크리스트에 따라 제출
      │
[검토·결제] 행정사 검토 + 대행 수수료 결제
      │
[접수 대행] 행정사가 하이코리아 접수 → 상태 추적
      │
[결과 통보] 승인/보완/불허 알림
```

| # | 화면 | 파일 | 핵심 요소 |
|---|---|---|---|
| 1 | 온보딩/홈 | `app/index.html` | 언어 선택, 서비스 소개, 챗봇 시작 CTA, 진행중 사건 요약 |
| 2 | AI 챗봇 상담 | `app/chat.html` | 대화 UI, 선택형 답변 버튼(퀵리플라이), 비자 추천 카드 |

| 4 | 서류 업로드 | `app/documents.html` | 체크리스트, 업로드 버튼, 서류별 상태 배지 |
| 5 | 진행 상태 | `app/status.html` | 단계 타임라인, 담당 행정사 정보, 문의 버튼 |
| 6 | 마이페이지 | `app/profile.html` | 프로필, 언어 설정, 결제 내역, 알림 설정 |

## 7. 기술 스택 제안

| 레이어 | 초안(프로토타입) | 프로덕션 제안 |
|---|---|---|
| 프론트엔드 | 정적 HTML/CSS/JS | Next.js(React) + PWA, i18n |
| 백엔드 | — | FastAPI 또는 NestJS |
| AI | 스크립트 데모 | Claude API + RAG(벡터 DB: pgvector 등) |
| 데이터 수집 | — | 하이코리아 크롤러/공공데이터 API + 스케줄러 |
| 스토리지 | — | S3 호환(서류 파일, 암호화 저장) |
| 인증 | — | 이메일/소셜 로그인 + 여권 정보 검증 |

## 8. 로드맵 (제안)

- **Phase 0 (현재)** — 초안 화면 프로토타입, 기획 확정
- **Phase 1 (MVP)** — 챗봇(RAG) + 상담 → 서류 체크리스트 생성, 행정사 수동 접수
- **Phase 2** — 서류 업로드/검토 워크플로, 결제, 상태 추적, 다국어
- **Phase 3** — 관리자 대시보드, 알림(카카오/이메일), OCR 서류 자동 검증
